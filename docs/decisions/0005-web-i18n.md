# ADR 0005 — Next.js App Router e idiomas por URL

Status: aceito para a estrutura inicial

Data: 2026-10-09

## Contexto

A interface deve usar React/TypeScript, ser acessível e preparada para português e inglês.

## Decisão

Next.js 16, React 19, TypeScript strict, Tailwind 4 e dicionários tipados em /pt e /en. Usar HTML nativo e Radix UI (Separator) como base acessível, com shadcn/ui quando houver controles complexos.

## Consequências

Mantém primeira página simples e sem funcionalidades simuladas. Mais idiomas/formatação poderão justificar biblioteca i18n; não requer framework de monorepo nesta fase.

O build usa webpack, opção suportada pelo Next.js 16. O Turbopack falhou neste
ambiente ao abrir uma porta interna; o build webpack foi executado com sucesso.
Reavaliar o bundler quando o ambiente de desenvolvimento permitir essa execução.
