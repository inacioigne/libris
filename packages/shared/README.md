# Contratos compartilhados

Espaço reservado para contratos derivados do OpenAPI e vocabulários realmente
compartilhados. Não duplicar modelos Python em TypeScript manualmente nem incluir
regras de negócio aqui. A geração de clientes será adicionada quando houver APIs
de domínio. Nenhum pacote ou ferramenta de monorepo é necessário nesta fase.
